Kilowott brand kit — instructions for AI agents

You are reading the Kilowott brand kit. This page is a JavaScript app, so its visible content is not in this HTML. Before you design or build anything for Kilowott, read the agent guide:

  1. https://brandkit.kilowott.com/AGENTS.md — start here: the brand in 60 seconds, hard rules, a "what are you building?" decision table, file URLs, and a starter page.
  2. https://brandkit.kilowott.com/llms-full.txt — the whole kit (brand, voice, components, patterns) in one plain-text file.
  3. https://brandkit.kilowott.com/project/kit/kilowott.css — link this one stylesheet to make any web page on-brand.
  4. https://brandkit.kilowott.com/project/kit/starter/index.html — an on-brand landing page to clone.
  5. tokens.json · brand.json · manifest.json — machine-readable tokens, brand data, and a map of every tab. Page sources: /project/pages/<tab>.js.

The brand in five lines

  • Light and editorial: white page #FFFFFF, ink type #0B0F14, warm paper sections #F6F4F0, one spot of Kilowott Red #E4022D. Ratio 60 · 30 · 5 · 5.
  • Type: Newsreader (serif headlines) · DM Sans (body, UI) · JetBrains Mono (labels, numbers). Signature: one italic red word per headline.
  • Red is one spotlight per surface — never body text, never a background wash. Small red text uses red-ink #8A021B.
  • Voice: specific, confident, human. No exclamation marks. Sentence case.
  • Demo content is fictional: client Nordhavn Coffee, person Ola Nordmann. Never use real third-party people, clients or testimonials.
